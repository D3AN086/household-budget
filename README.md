# Household Budget

A simple budget tracker for two people.

Open `index.html` on your phone, or visit the GitHub Pages site after it is enabled:

https://d3an086.github.io/household-budget/

## How to use

1. Tap **+ Add income** and enter each wage.
2. Tap **+ Add a bill** for rent, electric, wifi, food shop, and so on.
3. The app totals pay, bills, leftover cash, unpaid bills, and a daily leftover.
4. Tick a bill when it is paid this month.
5. Open **Share** to send a summary to your partner, or download a backup file they can load on their phone.

Numbers stay on the phone you use. Send a backup file or summary if you both want the same list.
